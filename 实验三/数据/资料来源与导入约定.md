# 曲库扩充资料来源与导入约定

原始清单为工作区根目录的《扩充歌单.md》，共 30 首、5 类。歌名、合作音乐人和专辑显示名称以用户清单为主；没有提供专辑发行日期，因此新专辑的 release_date 保持 NULL。

## 去重

去重使用歌曲名称及完整音乐人集合，不仅比较歌名。名称经过 Unicode NFKC、大小写与空格归一；本批明确映射 `新宝島 → 新宝岛`、`サカナクション（鱼韵） → Sakanaction`。Shelter、Look at the Sky 和新宝岛复用原记录，不覆盖其专辑、时长、音乐人或其他资料。Shelter 的 album_id 仍为 NULL。

新歌单沿用分类名称，挂在独立演示账号 tongpin_demo 下，设为公开，顺序与原清单一致。原有用户、喜欢和收藏关系不作批量修改。歌曲资料扩充本身不会自动生成新的用户喜欢记录。

## 补充资料

`扩充导入资料.json` 是审核后的导入数据，逐首保存时长、曲风和来源链接；`音乐资料候选.json` 等文件保留查询候选以便核对。没有下载封面、试听文件或音频。

时长主要参考 Apple 的歌曲条目，取 trackTimeMillis 的整数秒部分。检索结果中排除了明显的翻唱、现场、伴奏与 Remix，并优先选择清单所列发行版本。

- Apple Search API 说明：https://performance-partners.apple.com/search-api
- Chinese Football 乐队的官方 Bandcamp： https://chinesefootball.bandcamp.com/album/chinese-football ，《地球上最后一个EMO男孩》5:47。
- wowaka 的 Unhappy Refrain 专辑条目：https://musicbrainz.org/release/1b1de840-b0d1-4def-9fb5-929b13dca10c ，《ローリンガール》选用专辑版本 3:10，而非原投稿视频的时长。
- 陶喆《黑色柳丁》专辑条目：https://musicbrainz.org/release/bade1adc-6282-427e-802d-b523ab3ad434 ，标题曲 4:15。

少数合辑、再版与单曲在不同平台上的专辑名称及母带时长不同。本次仍保留清单所列专辑：丸の内サディスティック / MoRA、Blue Monday / International、360 / BRAT、Wake Me Up / True (Bonus Edition) 的时长参考同曲正式录音条目，未逐一核对该版本母带。相应说明也写入每首歌的导入 JSON，后续若提供指定版本可单独校正。原有 8 首课程样本的时长本次不改动。

## 执行及回退

```bash
cd 实验三
.venv/bin/python scripts/import_catalog.py --apply
```

交互输入 jp 的数据库密码。管理员须事先为 jp 授予 artist_id_seq、album_id_seq、song_id_seq、playlist_id_seq 的 USAGE、SELECT 权限；这些序列在前次迁移中由 omm 创建，原先没有对 jp 授权。Web 账号 music_web 的权限不扩大。

脚本在事务中锁定受影响表，导入前把六张相关表导出到 `备份/catalog_时间/before.json`。新建对象编号和复用对象写入 `manifest.json`，同目录的 `rollback.sql` 只删除本批新增对象，保留原来的歌曲与歌单。执行撤回前先备份当时状态；若后续新歌单已引用本批歌曲，外键会阻止相关删除，整笔事务应回滚。

不带 --apply 时执行后回滚，但序列取号不会回退。已经完成的同一批次再次执行应全部复用，不增加歌曲和分类歌单。需要修改已有分类歌单时，使用 Web 编辑或另行编写明确的更新操作。
